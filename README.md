\# Sunrise Dental Clinic Management System



A Java desktop application developed to streamline dental clinic operations, including patient appointment scheduling, billing, and staff authentication. Built using standard MVC architecture with MySQL persistence.



\## Key Features

\* \*\*User Authentication:\*\* Secure login for clinic receptionists with credential validation.

\* \*\*Appointment Management:\*\* Real-time appointment booking with doctor schedule conflict checks.

\* \*\*Patient Registration:\*\* Seamless registration of patient details during booking.

\* \*\*Billing System:\*\* Automated invoice generation, consultation fee calculations, and treatment fee lookups.

\* \*\*Automated Unit \& Integration Testing:\*\* 100% green bar test coverage using JUnit.



\## Technology Stack

\* \*\*Language:\*\* Java (JDK 8 / 17)

\* \*\*IDE:\*\* NetBeans IDE

\* \*\*Database:\*\* MySQL (XAMPP Server)

\* \*\*Testing:\*\* JUnit 4 / 5

\* \*\*Version Control:\*\* Git \& GitHub
